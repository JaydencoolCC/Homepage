[Automatic Dataset Construction (ADC)](https://arxiv.org/pdf/2408.11338) uses LLMs to design detailed class labels and generate search queries for efficient sample collection. We construct [Clothing-ADC](https://huggingface.co/datasets/mikelmh025/ClothingADC), a dataset of over 1 million images spanning 12 main classes and 12,000 fine-grained subclasse. Our automated curation achieves 79% agreement with human annotators and reduces label noise from 22.2% to 10.7%.
Our project also provides open-source software that integrates existing methods for detecting label errors and enabling robust learning with noisy and biased data in real-world applications.
